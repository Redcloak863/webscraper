# webscraper
My take on the HyperSkill webscraper project.
This isn't a very useful scraper. It's only for the Nature.com website. (They're nice enough to not Cloudflare us!) It does demonstrate some useful Beautiful Soup usage as well as some error trapping. (Pay-walled content uses different tags than non-pay-walled content. The project's instructions don't make that clear!) The code is gathered into some possibly unnecessary functions. I didn't know at the outset how or how often I needed to access some of the code. It does make it easier to follow the main function's logic.
